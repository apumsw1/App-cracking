# Brutal Admin Loader (Android Native)

Advanced mobile admin dashboard, app management utility, and diagnostic tool suite built with Kotlin and Jetpack Compose.

## Features
- **Dashboard & Telemetry**: Real-time CPU, RAM, storage, battery, and root status monitoring.
- **App Manager & Package Inspector**: Browse installed apps, inspect target SDKs, permissions, and package signatures.
- **Admin & Payload Tool Suite**: Dex decompression, network ping/traceroute, port scanner, SSL certificate auditor, and ADB shell command execution.
- **Security & Hardening Audit**: SELinux enforcement status, device encryption check, USB debugging status, and signature verification.
- **Log Monitor & Interactive Shell**: Live logcat stream and interactive terminal shell.
